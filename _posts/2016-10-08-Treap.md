A **Treap** is a balanced BST, which combines properties of BST and Heap. In addition to usual key, each node is also assigned a random priority. Nodes are ordered such that keys form a BST while priorities form a min-heap.

## Inserting a new node

First, assign node a random (but, unique) priority. Insert node into treap using usual BST insertion. Fix to make sure priorities obey the heap order.

(Not a BST with extract-min, as BST and heap are using different keys)
